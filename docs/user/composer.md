# Message composer

Messages can contain up to 120,000 characters. If a draft is longer, T3 Code keeps it in the
composer and shows how many characters need to be removed. Shorten the draft or split it into
multiple messages, then send again in the same thread.

## Usage limits

For Codex and Claude subscriptions, the composer shows a usage-limits ring next to the context
window meter. Hover it to see the 5-hour and weekly limit windows, how much of each is used, and
when they reset. The ring tracks whichever window is closest to its limit and turns red above 90%.
Limits appear once the provider reports them — shortly after a session starts — and update as you
work, with no extra polling of your account.
